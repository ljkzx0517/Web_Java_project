# Web Java Project

웹 프로그래밍 개인 프로젝트를 진행하기 위한 저장소입니다.

## 📌 프로젝트 소개

웹 프로그래밍 기술을 활용하여 개인 프로젝트를 개발하고,
개발 과정과 소스 코드를 관리합니다.

## 🎯 프로젝트 목표

- 웹 프로그래밍 기술 학습
- Java 기반 웹 애플리케이션 개발
- 데이터베이스 연동
- 프로젝트 구현 및 기능 개선

## 🛠 개발 환경 및 기술

- Java
- Eclipse
- HTML
- CSS
- JavaScript
- Oracle Database

## 📂 프로젝트 구성

프로젝트 진행 상황에 따라 소스 코드와 관련 자료를 정리할 예정입니다.

## 📝 개발 기록

- 프로젝트 기획
- 화면 및 기능 설계
- 데이터베이스 설계
- 기능 구현 및 테스트
- 최종 결과물 정리
